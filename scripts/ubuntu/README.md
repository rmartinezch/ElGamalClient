# Scripts Ubuntu

Estos scripts son para flujo local en Ubuntu/Linux.

- `bootstrap-verificatum.sh`: valida que existan las dependencias locales de Verificatum en `.mvn/local-repo`.
- `build-jar.sh`: valida dependencias y compila el JAR.
- `run-cifrador.sh`: compila (si hace falta) y ejecuta el JAR con parámetros del cifrador.
- `build-cifrador-portable.sh`: genera imagen portable en `dist/linux/image/Cifrador`.
- `package-cifrador-portable.sh`: comprime imagen portable en `dist/linux/*.tar.gz`.
